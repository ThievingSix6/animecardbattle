TREES
=====

Any number of .glb files, any names. Every file is a variant, and they
are dealt out between the park plots round-robin so a park is not one
tree copied.

Parks appear in the lots the skyline leaves empty - about one lot in
five is empty, and a bit over half of those become a park with a grass
pad and two to five trees.

Trees are scaled to 9-18 m, which is tall next to a 5.7 m player and
deliberately so: a city with trees the player can see over reads as a
model village. Change TREE_HEIGHT_MIN / TREE_HEIGHT_MAX in
scripts/lobby3d/lobby_world.gd to taste.

With this folder empty the parks build cone trees instead.
