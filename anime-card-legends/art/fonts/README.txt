DROP A FONT HERE
================

Put any .ttf or .otf file in this folder and the whole game will use it
automatically - no code changes, no editor work.

Optional: name files by weight for a proper hierarchy.
    regular.ttf   -> body text
    bold.ttf      -> card names, headings, numbers

If only one font file is present, it is used everywhere.

Good free choices for this art style (all free for commercial use):
  - Rajdhani        - condensed, techy, great for stat numbers
  - Chakra Petch    - angular sci-fi, very "gacha UI"
  - Exo 2           - clean geometric, highly readable at small sizes
  - Oswald          - tall condensed, strong for CARD NAMES
  - Inter           - neutral workhorse for body/description text

All are on Google Fonts (fonts.google.com) - download, unzip, drop the
.ttf in here. A common pairing: Oswald for names + Inter for body.
