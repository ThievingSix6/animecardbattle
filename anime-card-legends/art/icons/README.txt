ICONS
=====

Drop PNG or SVG files here named exactly as below and they replace the
emoji fallbacks everywhere. Missing files just keep using emoji, so a
partial set works fine - add them as you go.

  ROLES
    role_tank.png   role_dps.png   role_assassin.png
    role_healer.png role_support.png

  ELEMENTS
    element_fire.png   element_water.png  element_earth.png
    element_wind.png   element_light.png  element_dark.png

  UI / STATS
    gem.png    gold.png   pack.png   dice.png
    sword.png  shield.png heart.png  bolt.png

Sizing: square, 64x64 or 128x128 PNG with transparency is ideal. SVG
also works and scales cleanly.

Free sets that fit this style (all free for commercial use):
  - kenney.nl/assets/game-icons        (CC0, huge, game-focused)
  - game-icons.net                     (CC-BY, 4000+ fantasy/RPG icons -
                                        best match for roles/elements)
  - lucide.dev                         (MIT, clean line icons for UI)

Tip: icons are tinted in code, so plain white shapes on transparent
backgrounds work best.
